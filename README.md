# CodeQuest 🚀

**A Gamified Coding Learning Platform**

CodeQuest is a web-based coding learning platform designed to make programming education interactive and engaging through structured lessons, quizzes, progress tracking, and gamification.

## ✨ Features

### 👨‍🎓 Student Portal
- Student registration and login
- Structured coding lessons
- Interactive quizzes for each lesson
- Unlock the next lesson after scoring at least 80%
- Learning progress tracking
- Points and leaderboard system
- Daily streak tracking
- Learning Arena with coding practice questions
- Practice completion tracking

### 🛠️ Admin Portal
- Secure admin login
- Admin dashboard with platform statistics
- Add, edit, and delete lessons
- Manage quiz questions
- Manage practice questions
- View registered students and their progress

## 💻 Technologies Used

- SQLite
- Flask-Login
- HTML
- CSS
